# Release Rules

## Approval Gate

- Do not change versions, publish packages, or run release steps without explicit operator approval.

## Required References

- Read `docs/reference/RELEASING.md`.
- Read `docs/platforms/mac/release.md` for macOS release work.

## Safety Rules

- Treat signing, notarization, and publish credentials as externally managed.
- Prefer documented release steps over ad-hoc experimentation.
